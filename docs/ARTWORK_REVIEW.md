# Artwork review and answer ledger

## Current set

All 120 original paintings have a playable authored pair, with exactly five declared answers per pair (600 answers). Card-022 is the previously approved example; this expansion adds the other 119. Original JPGs are untouched. Final edited PNGs and full generation/correction prompts are saved under `public/artwork/differences/card-NNN-edited-v1.*`. Generation used the built-in image-generation tool, following the imagegen skill's precise-object-edit and non-destructive workflow.

Changes are chosen per painting, not from a red-bow/gold-button formula. They include meaningful existing-object colors, moon phases, expressions, missing pieces, fabric patterns, botanical details, architectural details and small decorative variations.

## Rendering and review scope

The game composites the five declared rectangles from each edited image over the original. Pixels outside those rectangles use the untouched original. Do not publish the full generated PNG as the game’s altered image: it can contain incidental generation drift outside the approved areas. The same normalized rectangles define hit detection and result outlines.

Each source and generated output was visually inspected, and descriptions/regions were adjusted to actual output. Several failed edits were regenerated. This is an editorial artwork pass, not a claim of pixel-perfect manual retouching: local texture drift and rectangular edge seams still need human review at high zoom. Browser spot checks do not substitute for a full human playthrough of 120 cards. Difficulty order is an estimate and has not been calibrated with players; the smallest details are deliberately zoom-dependent.

Small answer regions can sit within large changed objects. The smallest containing region wins, and a repeat hit there cannot fall through to score its parent. Tests check that every answer remains individually reachable.

## Review locally

Run `npm run dev` and open `http://127.0.0.1:5173/?review=card-120`, replacing 120 with any ID from 001 through 120. This override exists only in development. It still uses the daily share number, so review-mode scores must not be compared as daily results.

For every pair, inspect both images at normal size and high zoom, confirm five guesses, and inspect green Found outlines on the left and red Missed outlines on the right, with descriptions below. Check the six-second marker fade, Hide markers, and the reduced-motion static fallback. New day in development advances and resets the whole round. Check that the interesting object change—not a patch edge—is what gives away an answer. A real touchscreen playtest is still needed for physical pinch/drag and the tiniest targets.
