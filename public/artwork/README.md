# Temporary artwork

These 60 SVG placeholders were authored as original vector geometry in
`scripts/create-placeholder-artwork.mjs` for the Dreamerie prototype. No third-party
images, commercial-game assets, or AI image-generation services were used. They may
be used and modified within this project. They are temporary fixtures, not a final
art identity or a statement of the repository's overall license.

Ten scene compositions each have six structural variants, with consistent framing
and a shared palette family. Cards contain no concepts, player names, or ownership
labels. Metadata descriptions describe visible objects rather than intended meaning.

To reproduce the SVG files and `src/data/cards.ts` from the project root:

```powershell
node scripts/create-placeholder-artwork.mjs
```

Do not assign visual families to specific players or reserve a separate style for
decoys. All 60 cards belong to the same shared week pool.
